# 📡 Network Sniffer

Анализатор сетевого трафика.

## Возможности

- Захват HTTP запросов
- DNS мониторинг
- Перехват паролей в открытом виде
- Прокси-режим
- Экспорт логов

## Технологии

- Python 3.11
- socket, threading

## Установка

```bash
git clone https://github.com/Oncillaa/sniffer.git
cd sniffer
python sniffer.py
```
## ⚠️ Только для образовательных целей

## 🔧 Как это работает

1. Запускается как прокси на порту 8888
2. Браузер настраивается на этот прокси
3. Все запросы проходят через программу
4. Логируются URL, заголовки, данные

## ⚠️ Ограничения

- HTTPS виден только как CONNECT
- Не перехватывает не-браузерный трафик
