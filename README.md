# 📡 Network Sniffer

Анализатор сетевого трафика.

## Возможности

- Захват HTTP запросов
- DNS мониторинг
- Перехват паролей в открытом виде
- Прокси-режим
- Экспорт логов

## Технологии

- Python 3.11
- socket, threading

## Установка

```bash
git clone https://github.com/Oncillaa/sniffer.git
cd sniffer
python sniffer.py
```
